# Aura Gallery

A responsive image gallery project for CodeAlpha Frontend Development Task 1.

## Files
- `index.html` — page structure
- `style.css` — layout, responsive styles, and visual design
- `script.js` — categories, search, favorites, and lightbox behavior

## Run locally
1. Keep all three files in the same folder.
2. Open `index.html` in a browser. If your editor offers Live Server, you can use that too.
3. Internet access is required for the remotely hosted Unsplash images and Google Fonts.

## Included features
- Eight categories: Paintings & Art, Animals, Nature & Landscapes, Home Décor, Travel & Places, Food, Fashion & Lifestyle, and Flowers.
- Five gallery entries per category (40 total).
- Category cards and filter buttons.
- Search by title, description, or category.
- Favorites view (in-memory for this version; refresh clears favorites).
- Lightbox with previous/next navigation, keyboard arrow keys, Escape to close, and favorite toggle.
- Hover effects, responsive layout, mobile navigation, reduced-motion support, image loading fallbacks.

## GitHub submission
Create a repository named `CodeAlpha_ImageGallery`, upload the three source files (and this README if desired), then enable GitHub Pages from the repository's Settings.

## Image note
Images are loaded from Unsplash image URLs. A network issue or an unavailable remote image may cause an image not to load. For a fully offline project, download images you have permission to use into an `images` folder and replace the URLs in `script.js` and `index.html`.
